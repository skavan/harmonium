# The Harmonium cookbook

*Purpose: The index of task-shaped guides — each one ends with a concrete outcome on your remote. Audience: users, after install.*

Task-shaped guides: each page starts from a working install
([GETTING-STARTED](../GETTING-STARTED.md)) and ends with one concrete
outcome on your remote.

**📺 Video tutorials:** [Install via HACS](https://youtu.be/2E28x7pt36k) ·
[Watch TV activity](https://youtu.be/M75ZPYvorUM) ·
[Listen to Music activity](https://youtu.be/vALzJylJLSw) ·
[Presets & Devices](https://youtu.be/lhVmuL7QHfs)

| Guide | You end up with |
|---|---|
| [Your first screen](first-screen.md) | Your first page, scaffolded and deployed — the foundation |
| [Activities](activities.md) | "Watch TV" that turns everything on, in order |
| [Creating an Activity — the deep dive](creating-an-activity.md) | Every tab, every knob, every concept, with screenshots |
| [Presets](presets.md) | One-tap Netflix / scene / favorite buttons |
| [Mapping a physical remote](remote-map.md) | A new remote model fully described, end to end |
| [Creating a dialect](creating-a-dialect.md) | Teach a new platform (Apple TV) its apps, keys and wake |
| [The device photo](device-photo-skin.md) | The Studio preview inside a photo of *your* remote |
| [Hardware keys](hardware-keys.md) | Physical buttons doing the right thing on every page |
| [Battery alerts](battery-alerts.md) | A remote that nags before it dies — even while asleep |
| [Workspaces](workspaces.md) | A second remote with a different world |
| [Theming](theming.md) | Your accent, your radius, per-device fonts |
| [Wipe & reinstall](wipe-and-reinstall.md) | A box with zero trace of Harmonium — the virgin-install test |
| [Removing Harmonium](remove-harmonium.md) | Complete removal — HA, data, tokens, and the remotes |
| [Cutting a release](releasing.md) | make-release → commit → tag matching the manifest → rollout |

The config contract itself (hand-edited JSON for anything the Studio
doesn't surface yet) is [screen-schema.md](../screen-schema.md).
Pre-Studio recipes are preserved at `archive/docs/cookbook-v1.md`.
