# Ownership buckets — who wins, for every part of an install

v0.85.7 · The grown-up strategy. Suresh: "Identify every single part
of our project and bucket it into (a) stock [repo always wins]
(b) variant [repo and user config might fight] (c) user [user config
always wins]. The goal is that when we make changes to the repo, we
don't (a) strand users on legacy but also (b) we keep their custom
changes."

This document is the complete inventory and the rules. The referee
that enforces bucket (b) lives in `studio-src/src/lib/ownership.js`;
its memory is `studio-src/src/lib/stock-history.js` (generated by
`tools/gen-stock-history.mjs`); `tests/probe-ownership.mjs` and
`tests/probe-ownership-ui.mjs` pin the behaviour; `probe-stock-sync`
fails the build when any stock truth drifts or the history goes stale.

## The three buckets

**(a) STOCK — the repo always wins.** Things that are ours by
position or by definition. Updates refresh them unconditionally; the
user was never able to edit them in place (or the place itself says
so). Losing a local difference here is not data loss — it's repair.

**(c) USER — the user always wins.** Things we never created and can
never regenerate: their pages, their activities, their photos, their
remapped keys. No update may touch these, ever. Stranding is
impossible by construction because there is no "current" for us to
strand them from.

**(b) VARIANT — the fight zone.** Things that START as ours but were
historically editable in place (the pre-lock era), or that carry both
our facts and their choices in one object. Every bug of the last two
weeks lived here. The referee decides each case by **content
fingerprint**:

> A copy whose fingerprint matches ANY shape we ever shipped is
> pristine — it is still ours, and it heals to current silently.
> Anything else under a stock id was edited by the user — it becomes
> their fork, formally: `variant_of` stamped, unlocked in the Studio,
> never healed again, with a `forked_by_update` note so the Studio
> can explain what happened and offer **↺ Reset to built-in**.

Failure direction, chosen deliberately: an unrecognized-but-actually-
pristine shape (an intermediate heal state we failed to enumerate)
costs the user a notice and a one-tap reset — never their data, and
never a silent stranding. The reverse mistake would require a sha1
collision.

## The inventory

### Config organs (config.json)

| Organ | Bucket | Rule |
|---|---|---|
| `controllers.<stock id>` (music, tv, apps, music_library, media, domain stocks) | **(b)** | Referee: pristine → heal to current; edited → legitimized fork; `variant_of` → never touched. Protected key inside: `parent` (content-graph edge, survives heal). |
| `controllers.<user id>` (⧉ duplicates, per-device copies, their own) | **(c)** | `variant_of` marks them; no healer may look at them. |
| `screens.*` (their pages) | **(c)** | Never touched. |
| `activities.*` (incl. `surface` band prefs, np_style) | **(c)** | Never touched. |
| `remotes.<stock id>` — the profile as a whole | **(b)**, per key: | |
| — `capabilities` | **(a)** | Hardware facts, not preferences (no Studio editor exists). Heal by UNION — add missing stock caps, never remove. |
| — `keymap` | **(b)** | Fingerprint: any shipped keymap → refresh to current (new stock keys arrive); one remapped key → theirs verbatim. Engine still backfills hold-keys only-if-absent at runtime. |
| — `skin` | **(b)** | Ownership by image path + fingerprint: `stock/` path or a shipped flat name → ours, geometry heals by gen; user photo (`user/` path, or any name we never shipped flat, e.g. flat `rs90.png`) → theirs, untouched. |
| — `style`, `fully`, battery sensors | **(c)** | Theirs. |
| `remotes.<user id>` (incl. `default`) | **(c)** | Only capabilities of STOCK ids are unioned; everything else untouched. |
| `dialects.<stock id>` (firetv, tizen, googletv, appletv) | **(b)** | Fingerprint, whole-unit: matches ANY shipped shape → tracks stock WHOLESALE (new apps and fixes arrive — the tombstone problem dissolves for untouched dialects); one edit — a deletion counts — and it is the user's, untouched entirely. The Apps editor shows the state on each stock dialect (● Stock / ✎ Yours) with **View stock** (read-only JSON to copy from) and **↺ Reset to stock**. Plant-if-absent still covers a missing dialect. |
| — `dpad_commands` (on an edited dialect) | **(b)** | Fingerprint: shipped or absent → refresh to current; edited → theirs. |
| — `apps` map (on an edited dialect) | **(c)** | Theirs; only a fully EMPTY map is backfilled. Residual gap: an EDITED dialect no longer receives new stock apps — by design, with View stock as the copy-paste door. |
| `apps` master list | **(b)** | Stock identities plant-if-absent (`STOCK_APP_IDENTITIES`); their apps are theirs. |
| `keymap` (global fallback) | **(c)** | Engine backfills hold-keys only-if-absent. |
| `theme`, `entity_options`, `devices` (bundle library), `speaker_groups`, `snippets`, `sequences`, `input policy`, `workspaces`, `global` (room/select wiring), `home_screen`, `screen_order` | **(c)** | User/system state. Never touched by any healer. |
| `version` | **(a)** | Schema number; migrations own it. |

### Deployed files (www/harmonium/)

| File(s) | Bucket | Rule |
|---|---|---|
| `index.html` (engine), `studio.html` | **(a)** | Stamp-guarded self-deploy: overwrite only what matches our own stamp; a manual dev push is left alone until the next release catches up. |
| `skins/stock/*` | **(a)** | Positional: only deploy writes here; upload returns 403. |
| `skins/user/*` | **(c)** | Positional: only user uploads land here; deploy never writes. |
| `skins/*` flat (legacy) | **(b)** | Fingerprint-fenced compat window: only names we shipped flat (astrion, astrion2), adopted only at bytes we shipped (`PRE_SPLIT_FLAT_FPS`); everything else — including any flat `rs90.png` — is a user photo, frozen. |
| `sounds/*` | **(b)** | Per-asset stamps: ours updates, theirs (replaced files) freeze. |
| `config.json` | **(c)** as a file | Healed organ-by-organ per the table above; never regenerated wholesale. |

### Repo-side truths (the other half of the contract)

| Truth | Guard |
|---|---|
| stocklib shapes ≡ starter-config shapes | `probe-stock-sync` (controllers, dialects, app identities, remote profiles, gens never-ahead) |
| stock-history.js contains every CURRENT shape | `probe-stock-sync` history-staleness check — a stock change without `node tools/gen-stock-history.mjs` fails the battery |
| starter skins ≡ STOCK_SKINS | `probe-stock-skins-sync` |
| flat-adoption fingerprints | `PRE_SPLIT_FLAT_FPS` in packaging.py, pinned by `test-asset-deploy.py` |

## The fingerprint

`ownership.js` — stable stringify (sorted keys, compact), sha1, first
12 hex. Normalization before hashing makes the fingerprint blind to:

- **bookkeeping** (`gen`, `parent`, `variant_of`, `forked_by_update`) —
  two copies differing only here are the same unit;
- **the safe-drift registry** — every key OUR OWN heal code has ever
  added/removed on stock copies, so a pristine config at any heal
  level still reads pristine: media-tile `style` (the v0.85.0 bake) and
  `np_default` (v0.85.x addition), controller `font_scope` (v0.52.1),
  `banner` (v0.50.2 removal), `context` (v0.48.2 purity strip), the
  `mq_pull` tile (v0.51 removal). **Rule: every new surgical heal adds
  its key here**, or its own output will misread as a user edit
  (harmless — legitimize + notice — but noisy).

The history: every tagged `starter-config.json` (extracted from git —
snapshots committed under `tools/starter-history/`) plus the current
stocklib truth, fingerprinted per unit. Regeneration is two commands,
documented at the top of `tools/gen-stock-history.mjs`; forgetting is
build-fatal, not silent.

## What the user sees

Nothing, in the happy path: pristine installs update silently and are
never stranded. When the referee finds a pre-lock edit, the Studio
shows, on that controller: **"Your edited copy, preserved."** — you
changed this built-in before it was locked, an update kept your
version, it's yours now, the built-in has moved on, reset any time —
with **↺ Reset to built-in** (returns the current stock shape and
restores the lock). `resetControllerToStock` handles the self-fork
(`variant_of === own id`) by pulling `currentStockController(id)` and
clearing the bookkeeping.

## Known gaps, stated honestly

1. ~~Stock-dialect app additions~~ CLOSED (v0.85.7): pristine
   dialects track stock wholesale by fingerprint; edited dialects are
   the user's, with View stock / Reset to stock in the Apps editor.
2. **Fork-outdated "shout"**: a real ⧉ fork whose SOURCE has since
   moved on gets no notice yet. The data is there (`variant_of` + the
   stock's gen); a Studio banner "the built-in this was copied from
   has been updated — compare?" is designed but not built.
3. **Slipstream diff**: on legitimize we keep the user's whole copy;
   we do not yet offer "here is what the new stock adds that your
   copy lacks". The fingerprint infrastructure makes this buildable.
